DCCExpressLite

ESP32 / EX-CSB1

Ezzel az oldallal közvetlenül a böngészőből telepíthető a DCCExpressLite firmware az USB-n csatlakoztatott ESP32-re.

Telepítés
  1. Csatlakoztasd az ESP32 / EX-CSB1 eszközt USB-n.
  2. Chrome vagy Edge böngészőben nyomd meg az alábbi gombot.
  3. Válaszd ki az eszközhöz tartozó soros portot.
  4. Indítsd el a telepítést, és ne húzd ki az USB kábelt a folyamat közben.

A böngésződ nem támogatja a Web Serial kapcsolatot. Használj asztali Chrome vagy Edge böngészőt.
Otthoni Wi-Fi beállítása USB-n

A firmware telepítése és újraindulása után add meg az otthoni hálózatot. A böngésző elküldi a beállítást a DCC-EX soros portjára, az eszköz elmenti, majd automatikusan újraindul.

Soros monitorból ugyanez a parancs használható 115200 baud mellett:
<WIFI "OtthoniSSID" "jelszó">

Ha az USB-s beállítás nem érhető el

Csatlakozz a DCCExpressLite saját setup Wi-Fi hálózatára, majd nyisd meg a 192.168.4.1 címet. Ugyanaz az SSID és jelszó az eszköz Settings oldalán is elmenthető.

A telepítő egy GitHub Actions során előállított, egyesített ESP32 image-et használ. Ebben benne van a bootloader, partíciós tábla, firmware és a DCCExpressLite webes felületet tartalmazó LittleFS image is.
