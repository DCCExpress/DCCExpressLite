# DCCExpressLite starter data

This versioned starter package contains a small sample layout, four example locomotives, and their matching PNG images. Clean firmware builds automatically embed these files in LittleFS, so a newly flashed merged image opens with usable sample data.

The locomotive DCC addresses are examples. Review and edit them before operating a real layout. Existing local `data/layout.json` and `data/locos.json` files are never overwritten by the build-time staging step.
